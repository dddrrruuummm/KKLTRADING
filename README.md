# KKL TRADING

English corporate trade website for KKL TRADING CO., LTD., an Ontario corporation. Its incorporation documents do not name a specific product category, so the site presents a careful sourcing, trade coordination, and commercial inquiry structure rather than claiming an unverified catalog.

## Deployment

Deploy the project root to GitHub and Vercel. Do not upload `node_modules` or `.next` when using GitHub's web uploader.

Update `lib/site.ts` with the approved domain and public contact details before launch. Product program names and unique visuals are centralized in the same file and `public/images/`.
